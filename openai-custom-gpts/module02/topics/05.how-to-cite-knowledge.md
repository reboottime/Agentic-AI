# How to Cite Knowledge in Custom GPTs

## Key Learning Points

### Best Practice: Direct Quotations
- **Use Direct Quotations**: Provide exact text from source documents
- **Include Page References**: Specify where the quotation appears
- **Use Quotation Marks**: Clearly signal that text is a direct quote

### Why Direct Quotations Work Best
1. **User Verification**: Users can see the original language and decide for themselves
2. **Fact-Checking**: Users can verify the quotation exists in the original document
3. **Transparency**: Clear source attribution builds trust
4. **Error Detection**: Easy to spot mistakes by comparing to original

### Implementation Strategy
- **Provide Series of Quotations**: Don't limit to single quotes
- **No Discussion Initially**: Present facts first, let user interpret
- **Supporting Information**: Give users evidence to reason about
- **Consistency Checking**: Enable users to verify accuracy

### Benefits
- **Reduced Risk**: Minimize chance of misinterpretation
- **User Empowerment**: Let users make informed decisions
- **Accountability**: Easy to trace back to source material
- **Quality Control**: Users can fact-check responses

### Simple Implementation
- Use prompt: "Provide direct quotations from the document"
- Include page numbers or document sections
- Present quotations without interpretation
- Let users reason about the information

## Key Takeaway
When working with knowledge bases, provide direct quotations with clear citations rather than interpretations. This approach minimizes risk, enables fact-checking, and empowers users to make informed decisions based on the original source material.
