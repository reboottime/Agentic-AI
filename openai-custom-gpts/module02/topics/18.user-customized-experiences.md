# User-Customized Experiences: Personalization Through Context

## Key Learning Points

### Core Concept: User-Specific Customization
- **Role-Based Responses**: Different answers for different user types
- **Context-Aware**: Responses depend on user's position and circumstances
- **Personalized Experience**: Tailored information for each user's situation
- **Dynamic Adaptation**: GPT adjusts behavior based on user context

### Implementation Strategy
- **Always Start**: Begin by asking about user's role and position
- **Customize Answers**: Use role information to provide appropriate responses
- **Only After Context**: Don't attempt to answer until user role is known
- **Explicit Instructions**: Make this requirement clear in GPT instructions

### Example: Vanderbilt Travel Policy
- **CS Faculty**: Cannot get reimbursed for in-flight Wi-Fi (new policy)
- **Other Faculty**: Can get reimbursed for in-flight Wi-Fi (original policy)
- **Same Question, Different Answers**: Role determines the response

### Benefits
- **Accurate Responses**: Role-specific information leads to correct answers
- **Personalized Experience**: Users get relevant information for their situation
- **Reduced Confusion**: Clear, applicable guidance for each user type
- **Better Decision-Making**: Users can make informed choices based on their role

### Use Cases
- **HR Benefits**: Different benefits for different employee types
- **Educational Content**: Grade-level appropriate materials
- **Compliance**: Role-specific requirements and restrictions
- **Training**: Position-specific learning paths

### Design Considerations
- **Context Collection**: Gather user information before problem-solving
- **Role Dependencies**: Many policies depend on user's position
- **Dynamic Responses**: Same question can have different answers
- **User Identification**: Always start by understanding who the user is

## Key Takeaway
User customization is essential for many custom GPTs. By always starting with user identification and role collection, you can provide accurate, personalized responses that are relevant to each user's specific situation and circumstances.
