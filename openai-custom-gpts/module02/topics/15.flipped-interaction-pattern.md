# Flipped Interaction Pattern: GPT Asks Questions

## Key Learning Points

### Core Concept: Reverse the Interaction
- **GPT Asks Questions**: Instead of users asking GPT, GPT asks users questions
- **Information Elicitation**: GPT gathers needed information through questioning
- **Adaptive Navigation**: GPT uses domain knowledge to ask the right questions
- **Goal-Oriented**: Continue questioning until sufficient information is gathered

### When to Use This Pattern
- **User Uncertainty**: When users don't know what information to provide
- **Complex Domains**: When users aren't complete domain experts
- **Process Guidance**: When users need help understanding the process
- **Context Building**: When comprehensive context is needed

### Implementation Strategy
1. **Set Goal**: Tell GPT what to achieve through questioning
2. **Question Limit**: Specify how many questions to ask at once
3. **Trigger First Question**: Start the process with initial question
4. **Continue Until Goal**: Let GPT decide when it has enough information

### Benefits
- **User Guidance**: Helps users understand what information is needed
- **Better Context**: Gathers comprehensive information for better responses
- **Reduced Burden**: Users don't need to know what to ask
- **Adaptive Process**: Questions adapt based on user responses

### Example Use Cases
- **Recipe Creation**: Ask about preferences, ingredients, dietary restrictions
- **Travel Planning**: Gather destination, budget, preferences, constraints
- **Problem Diagnosis**: Collect symptoms, context, previous attempts
- **Custom Solutions**: Understand requirements, constraints, preferences

### Best Practices
- **Clear Goal**: Specify what the questioning should achieve
- **Question Pace**: Control how many questions asked at once
- **User Control**: Allow users to stop and let GPT fill in the rest
- **Goal Achievement**: Let GPT decide when it has sufficient information

## Key Takeaway
The flipped interaction pattern is powerful when users don't know what information to provide. By having the GPT ask questions, you can gather comprehensive context and guide users through complex processes, leading to better outcomes and more accurate responses.
