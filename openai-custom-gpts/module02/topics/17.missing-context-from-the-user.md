# Missing Context from the User: Role-Based Customization

## Key Learning Points

### Problem: Missing User Context
- **Role Dependencies**: Many policies and decisions depend on user's role
- **Incomplete Information**: GPT can't provide accurate answers without user context
- **One-Size-Fits-All**: Generic responses don't work for role-specific situations

### Solution: Flipped Interaction for User Identification
- **Ask First**: Always start by asking about user's role and position
- **Customize Responses**: Tailor answers based on user's specific role
- **Context Collection**: Gather user information before attempting to answer
- **Role-Specific Logic**: Apply different rules based on user's position

### Implementation Strategy
1. **Always Start**: Begin every interaction by asking about user's role
2. **Customize Answers**: Use role information to provide appropriate responses
3. **Only After Context**: Don't attempt to answer until user role is known
4. **Explicit Instructions**: Make this requirement clear in GPT instructions

### Example: Vanderbilt Travel Policy
- **CS Faculty**: Cannot get reimbursed for in-flight Wi-Fi
- **Other Faculty**: Can get reimbursed for in-flight Wi-Fi
- **Role Matters**: Same question, different answers based on user's position

### Benefits
- **Accurate Responses**: Role-specific information leads to correct answers
- **Personalized Experience**: Users get relevant information for their situation
- **Reduced Confusion**: Clear, applicable guidance for each user type
- **Better Decision-Making**: Users can make informed choices based on their role

### Use Cases
- **HR Benefits**: Different benefits for different employee types
- **Educational Content**: Grade-level appropriate materials
- **Compliance**: Role-specific requirements and restrictions
- **Training**: Position-specific learning paths

## Key Takeaway
Many custom GPTs need to know who the user is to provide accurate responses. Use the flipped interaction pattern to always start by asking about the user's role, then customize responses accordingly. This ensures users get relevant, accurate information specific to their situation.
