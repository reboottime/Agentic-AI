# Output Formatting with the Template Pattern

## Key Learning Points

### Template Pattern Overview
- **Control Output Structure**: Use templates to standardize GPT responses
- **Consistent Formatting**: Ensure responses follow predictable patterns
- **Better User Experience**: Present information in logical, readable formats

### Template Components
1. **Markdown Headings**: Use # for main headings, ## for subheadings
2. **Placeholders**: Use <placeholder> syntax to indicate where content goes
3. **Constraints**: Specify options like "yes|no|maybe" for answers
4. **Complex Instructions**: Describe detailed requirements for each section

### Implementation Example
```markdown
# Answer: <yes|no|maybe>

## Supporting Information
<direct quotations from the document...>

## Discussion
<discuss the quotations and how they support your answer>
```

### Key Benefits
- **Consistency**: All responses follow the same structure
- **User-Friendly**: Information is presented in logical order
- **Controllable**: You determine what information appears first
- **Professional**: Clean, formatted output looks more polished

### Template Design Tips
- **Use Placeholders**: `<content>` syntax for dynamic content
- **Specify Options**: Use pipes (|) to limit choices
- **Add Context**: Use "..." to indicate multiple items
- **Complex Instructions**: Describe detailed requirements in placeholders

### Markdown Knowledge
- **Headings**: # for H1, ## for H2, ### for H3
- **Formatting**: Bold, italic, lists, etc.
- **Structure**: Organize information hierarchically

## Key Takeaway
The template pattern allows you to control and standardize the output format of your custom GPT, ensuring consistent, professional, and user-friendly responses that present information in the most effective way for your users.
