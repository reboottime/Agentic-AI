# Handling Ambiguity in Concept Mapping

## The Problem

When users ask questions using terms or concepts that don't have a clear 1:1 mapping to your policy or knowledge base, ambiguity arises. This happens when:

- Users mention concepts that don't appear in the policy at all
- Users use terms that have multiple possible interpretations when mapped to your policy
- The same user question could lead to totally different results depending on how concepts are mapped

This creates a dangerous situation where the GPT might make incorrect assumptions and provide wrong answers.

## The Solution

Build ambiguity detection and response strategies into your custom GPT using this prompt:

```md
Always start by analyzing the user's question and determining if there are any concepts discussed in the question that cannot be unambiguously mapped into concepts in the policy.

If there are any concepts that have multiple possible mappings, state that the answer is unclear and suggest possible questions that you could answer instead using the concepts in the policy in this format.
```

### How It Works

1. **Detection**: The GPT analyzes every user question for ambiguous concept mappings
2. **Response**: When ambiguity is detected, the GPT:
   - States that the answer is unclear
   - Explains what concept is ambiguous
   - Suggests alternative questions using policy-defined terms

### Example

**User asks:** "Can I get reimbursed for Southwest Business Select?"

**GPT responds:**

- "The answer is unclear because the concept 'Southwest Business Select' is not mentioned in the policy"
- "Questions I can answer instead:"
  - "Can I get reimbursed for purchasing economy coach class airfare?"
  - "Are airfare upgrades reimbursable under the policy?"

### Benefits

- **Safety**: Prevents incorrect assumptions and wrong answers
- **Helpfulness**: Still provides value by suggesting related questions
- **Transparency**: Users understand why their question can't be answered directly
- **Guidance**: Helps users rephrase using policy-defined terms
