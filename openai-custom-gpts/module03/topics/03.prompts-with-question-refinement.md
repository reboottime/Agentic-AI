# Prompts with Question Refinement

## The Problem

Users often ask vague or ambiguous questions that can be interpreted in multiple ways. This leads to:
- Incorrect answers based on wrong assumptions
- Confusion when the GPT answers a different question than intended
- Risk of providing misleading information

## The Solution

Use the **Question Refinement Pattern** to automatically improve user questions before answering them.

### The Core Pattern

```md
Always start by analyzing the user's question and thinking of a better version of it. Provide the user the suggested better version of the question, and then ask the user if they would like to answer that question instead.
```

### How It Works

1. **Automatic Analysis**: GPT analyzes every user question for clarity
2. **Question Improvement**: Suggests a more specific, clear version
3. **User Choice**: Asks if they want to use the refined question
4. **Safe Response**: Only answers after user confirmation

### Examples

**Original:** "Can I get reimbursed for gas?"
**Refined:** "Under what circumstances can I be reimbursed for fuel expenses while traveling for Vanderbilt business?"

**Original:** "Can I get paid back for a Chevy Tahoe?"
**Refined:** "Can I be reimbursed for the use of a Chevy Tahoe while traveling on Vanderbilt business?"

### Benefits

- **Clarity**: Makes ambiguous questions specific and clear
- **Safety**: Prevents misinterpretation and wrong answers
- **User Learning**: Teaches users to ask better questions
- **Feedback Loop**: User can correct if refinement is wrong
- **Risk Reduction**: Reduces chance of providing incorrect information

### Key Principle

The pattern automatically augments user input to get better instructions going into the GPT, helping identify situations where the GPT might have misinterpreted the user's intent.
