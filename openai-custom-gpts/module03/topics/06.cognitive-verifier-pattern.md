# Cognitive Verifier Pattern

## The Problem

Complex user questions often require breaking down into multiple sub-questions to provide accurate answers. Many questions contain implicit assumptions or require clarification on key concepts before a proper answer can be given.

For example, when asking about travel policy reimbursements, questions like "Is this reasonable and appropriate?" require sub-questions such as:
- What is "reasonable and appropriate"?
- How do you define upgrades?
- What are the specific criteria?

## The Solution

Use the Cognitive Verifier Pattern to break down complex questions into 3-4 sub-questions that can be answered individually, then combined to provide a comprehensive answer.

### The Prompt

```md
Always start by analyzing the user's question and thinking of three to four sub-questions that could be answered that would allow you to give a better answer to the original question.

Then output the questions in the following format and ask the user if they'd like to proceed with asking and answering these questions.
```

### How It Works

1. **Analysis**: Break down the user's question into 3-4 specific sub-questions
2. **Presentation**: Show the user the approach and sub-questions
3. **Approval**: Ask if they want to proceed with this approach
4. **Execution**: Answer each sub-question individually
5. **Synthesis**: Combine the answers to provide the final response

### Example

**User asks:** "Can I get reimbursed for Southwest Business Select?"

**GPT responds:**
"To answer whether you can get reimbursed for Southwest Business Select, let's answer these questions first:

1. What type of airfare classes are reimbursable under Vanderbilt travel policy?
2. Are there specific restrictions or approvals required for reimbursing higher classes of airfare like business select?
3. How does the policy define necessary and reasonable expenses for air travel?

Would you like to proceed with answering these questions to clarify your query about reimbursement?"

### Benefits

- **Better Reasoning**: GPTs perform better when breaking problems into smaller steps
- **Transparency**: Users see the reasoning process and can verify the approach
- **Completeness**: Ensures all aspects of a complex question are addressed
- **User Control**: Users can approve or modify the approach before proceeding
- **Detailed Answers**: Each sub-question gets focused attention for more accurate responses
