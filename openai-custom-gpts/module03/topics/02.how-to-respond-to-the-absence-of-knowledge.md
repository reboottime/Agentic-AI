# How to Respond to the Absence of Knowledge

## The Problem

Users often ask questions that aren't clear or specific enough. When questions are ambiguous, the GPT might:
- Provide incorrect answers based on wrong assumptions
- Answer a different question than what the user intended
- Create confusion due to misinterpretation

## The Solution

Use the **Question Refinement Pattern** to automatically suggest better versions of user questions before answering them.

### The Prompt

```md
Always start by analyzing the user's question and thinking of a better version of it. Provide the user the suggested better version of the question, and then ask the user if they would like to answer that question instead.
```

### How It Works

1. **Analysis**: The GPT analyzes the user's question for ambiguity
2. **Refinement**: It suggests a clearer, more specific version
3. **Approval**: Asks the user if they want to use the refined question
4. **Response**: Only answers after user confirms the refined question

### Example

**User asks:** "Can I get reimbursed for gas?"

**GPT responds:**
"A better version of the question might be: 'Under what circumstances can I be reimbursed for fuel expenses while traveling for Vanderbilt business?'

Would you like me to answer this refined question instead?"

### Benefits

- **Reduces Ambiguity**: Makes questions more specific and clear
- **Prevents Misinterpretation**: User can correct if the refinement is wrong
- **Better Answers**: More specific questions lead to more accurate responses
- **User Education**: Helps users learn to ask better questions
- **Risk Mitigation**: Reduces chance of providing wrong information

### Key Insight

This pattern helps identify when the GPT might misinterpret user intent. If the user says "no, that's not what I meant," the GPT gets valuable feedback about the user's actual intent.
