# Knowledge Conflict Resolution

## The Problem

When using multiple documents, policies, or information sources in AI systems, conflicts and ambiguities inevitably arise at the intersection of these sources. For example:

- Multiple policies with different dates
- Conflicting information between documents
- Ambiguous interpretations when sources overlap
- Need to determine which source takes precedence

**Example scenario:** A travel policy system with two documents:

1. Current Vanderbilt Travel and Business Expense policy (newer)
2. Fake skydiving policy (older date) claiming skydiving is reimbursable for team-building

The conflict: Current policy doesn't mention skydiving, but older policy allows it.

## The Solution

Define explicit conflict resolution strategies that determine how the AI handles ambiguities and conflicts between multiple information sources.

### Strategy 1: Most Recent + Legacy Coverage

```md
Always use the most recent document or policy to answer the question. If there is a more recent policy that does not explicitly change or redefine an existing policy, you can assume that existing policy also applies.
```

**Result:** Skydiving is reimbursable because it's not explicitly prohibited in the newer policy and is covered in the older policy.

### Strategy 2: Most Recent Only (Comprehensive)

```md
Always use the most recent document or policy to answer the question. If there is a more recent policy, you should assume that is complete and only it applies. Anything not mentioned in the policy, but in older policies is no longer in effect.
```

**Result:** Skydiving is not reimbursable because it's not mentioned in the current comprehensive policy.

## Key Considerations

- **Document dating:** Establish clear rules for temporal precedence
- **Coverage scope:** Define whether newer documents are comprehensive or additive
- **Explicit vs. implicit:** Determine how to handle unmentioned items
- **Consistency:** Apply the same strategy across all similar conflicts
- **Transparency:** Make conflict resolution rules clear to users

The choice between strategies significantly impacts AI responses and user outcomes, making this a critical design decision for multi-source AI systems.
